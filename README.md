An adorable interactive desk lamp with a pull cord, glowing warm light, and a cute animated face. Pure HTML, CSS & JavaScript — no dependencies.

---

## ✨ Features

- 🪔 **Pull-cord interaction** — drag the cord to toggle the light
- 💡 **Glowing light effect** — warm CSS drop-shadow bloom
- 😊 **Cute face** — eyes, cheeks, and mouth on the lamp shade
- 🎨 **Smooth CSS transitions** — on/off state animation
- ♿ **Accessible** — keyboard accessible cord, ARIA labels
- 📱 **Responsive** — works on all screen sizes
